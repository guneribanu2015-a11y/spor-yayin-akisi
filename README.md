# Spor Yayın Akışı (kişisel)

Sporekrani.com verisinden önümüzdeki 7 günün tüm canlı maçlarını (beIN, S Sport, TRT, tabii, HT Spor, A Spor, Prime Video, Tivibu, kulüp kanalları…) günde 3 kez (06:00 / 12:00 / 18:00) çeker ve telefonda açılan tek sayfada gösterir.

- Sayfa: https://guneribanu2015-a11y.github.io/spor-yayin-akisi/
- Elle güncelleme: Actions → "Yayın akışını güncelle" → Run workflow
- Ayar: `scripts/sporekrani.py` (gün sayısı, gizlenen yabancı kanallar, şifresiz kanal listesi)

Not: Kişisel kullanım içindir; veri sporekrani.com'a aittir.
